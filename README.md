## 🎯 Objetivo

Desarrollar una plataforma que permita monitorear equipos industriales y detectar posibles fallas de manera temprana, facilitando la gestión del mantenimiento y los repuestos necesarios.

## 📌 Funcionalidades

### 📡 Monitoreo de equipos
- Registro de equipos industriales.
- Registro y consulta de datos de sensores.
- Visualización del estado de los equipos.

### 🤖 Detección de fallas
- Análisis de los datos obtenidos de los sensores.
- Detección de posibles anomalías mediante Machine Learning.
- Generación de alertas ante posibles fallas.

### 🛠️ Órdenes de trabajo
- Creación de órdenes de mantenimiento.
- Asignación de órdenes.
- Seguimiento del estado de las órdenes.
- Registro de las actividades realizadas.

### 📦 Inventario de repuestos
- Registro de repuestos.
- Consulta de existencias.
- Actualización del inventario al utilizar repuestos.
- Alertas de bajo inventario.

## 🛠️ Tecnologías

- Java / Spring Boot
- Base de datos
- HTML, CSS y JavaScript
- Machine Learning
- Git y GitHub
